    <h1>Install ComponentIQ</h1>
    <p>
      Add the package to your app, import the global styles once, and wrap your
      app with the provider so every component can read the design tokens.
    </p>
  </section>

  <section className='ciq-checklist'>
    <div>
      <span>1</span>
      <h2>Install the package</h2>
      <p>Install ComponentIQ and make sure your app has React available.</p>

```bash
npm install @winniekagendo/componentiq
```

    </div>
    <div>
      <span>2</span>
      <h2>Import CSS once</h2>
      <p>Put your global stylesheet in your app root, layout, or main entry file.</p>

```tsx
import './globals.css';
```

```css
@import 'tailwindcss';
@import '@heroui/styles/css';
```

    </div>
    <div>
      <span>3</span>
      <h2>Add the provider</h2>
      <p>The provider writes CSS variables into its subtree.</p>

```tsx
import { ComponentIqProvider } from '@winniekagendo/componentiq';

export function RootLayout({ children }: { children: React.ReactNode }) {
  return <ComponentIqProvider>{children}</ComponentIqProvider>;
}
```

    </div>

  </section>

<section className='ciq-callout'>
  <h2>For Next.js</h2>
  <p>
    Import the CSS in <code>app/layout.tsx</code> or your global stylesheet. If
    a component uses browser interaction, keep it inside a client component
    boundary.
  </p>
</section>
